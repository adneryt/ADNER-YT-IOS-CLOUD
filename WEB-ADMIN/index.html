Avatar y hologramas

Bases de avatar y holograma, rutas de referencia y recursos descargables desde GitHub Releases.

Las bases de referencia no requieren archivos y no se descargan en la IPA. Puedes añadir tantas opciones como necesites. Las rutas de juegos son referencias documentales, no destinos ejecutables.

Gestor de rutas

Rutas seguras de la IPA y rutas externas únicamente documentales.

Las rutas con destino IPA se guardan en Documents o Caches de ADNER. Las rutas de referencia no se ejecutan ni conceden acceso a carpetas privadas de otras apps.

Publica esta página con GitHub Pages y configura el mismo projectId en App/cloud-config.json. GitHub Pages aloja el panel, GitHub Releases aloja archivos y Firebase RTDB guarda rutas, recursos y versiones.
Seguridad y límites
Las escrituras requieren Firebase Authentication con el UID administrativo autorizado en las reglas de Realtime Database. El manifiesto publicado es de lectura pública. Los archivos se descargan desde GitHub Releases públicos.
Máximo 30 MB por archivo en el cliente ADNER · 50 recursos por publicación · HTTPS · validación SHA-256 en la IPA.
